# v1.0.0 — Identidad jurídica + Acerca de

## Cambios principales
- Nueva identidad visual en tonos azul, gris y dorado.
- Nueva página pública `/acerca`.
- Información de colaboradores integrada.
- Enlaces a “Acerca de” desde Inicio y Dashboard.
- Revisión de copy en simuladores para enfatizar repetición ilimitada y retroalimentación.
- Botón “Repetir simulador” desde la pantalla de resultados.

## No incluye
- No cambia el esquema de base de datos.
- No modifica el SQL académico de semestres 3, 4 y 5.
- No altera todavía la lógica estricta del backend que exige el mínimo de preguntas válidas para iniciar un simulador.
